Обновление гибридного Джарвиса

Установка:
1. Останови Джарвиса.
2. Сделай резервную копию текущих main.py и gui.py.
3. Скопируй main.py и gui.py из этого архива в C:\Jarvis, заменив старые.
4. Запусти: .venv\Scripts\python.exe gui.py

Настройка:
1. В интерфейсе нажми «Настройки ИИ / API».
2. Укажи OpenAI-совместимый API endpoint, имя модели и API-ключ.
   Для Groq базовый endpoint обычно: https://api.groq.com/openai/v1
3. Нажми «Проверить API», затем «Сохранить».
4. Включи «Использовать облачный ИИ для сложных вопросов».

Маршрутизация:
- Вопросы с вопросительным знаком и фразы вроде «почему», «объясни», «сравни» отправляются в облако, если оно включено.
- Команды управления Windows и запросы про экран остаются локальными.
- Если облачный вызов не сработает, программа пробует обработать запрос через Ollama.

Совместимость:
- Endpoint должен поддерживать OpenAI Chat Completions API.
- Это изменение не требует установки дополнительной Python-библиотеки для API.
- API-ключ сохраняется в %APPDATA%\Jarvis\config.json. Он хранится в локальном файле обычным текстом: не делись им и не добавляй его в Git.
- При включении облачного режима текст сложных запросов отправляется выбранному внешнему провайдеру.
- Проверка синтаксиса Python выполнена, но полноценный тест требует действующего API-ключа и установленного окружения проекта.
